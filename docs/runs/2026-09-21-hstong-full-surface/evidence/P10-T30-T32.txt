Security review
- No secrets logged: library log sites are only client/client.go ("http request", "http
  error"). No log.*/fmt.Print in internal/, client/, pkg/. Redaction masks the sensitive
  keys and never exposes length.
- Key provenance: pkg/types/platformkeys.go documents both keys as public reference data
  (base64 SPKI from the published HStong docs); ADR 0005 authorizes committing them.
- Money: money-check OK; float64 only in resilience (token rates) and metrics
  (measurements), never for prices/quantities.
- Residual risk: SHA-1 is platform-mandated (SHA1WithRSA) and weak by modern standards;
  bundled keys may lag rotation (WithPlatformPublicKey overrides); a caller-supplied
  slog.Logger that bypasses logging.Redacting is outside SDK control; the circuit breaker
  counts mutation failures when enabled (off by default).
