## Wire assumptions that stay UNCONFIRMED until this runs

1. **Market `int64` representation (ADR 0007).** `basicQot[].volume`,
   `ticker[].volume`, and `ticker[].timestamp` are assumed to be JSON **numbers**
   because `pkg/hstong/market` decodes with `encoding/json` over generated
   `int64` DTO fields. A quoted string would be a real-Gateway/ADR mismatch.
2. **`volumeStr`.** Assumed JSON **string** when present.
3. **`/trade/TradeQueryMaxAvailableAsset` envelope.** The SDK's
   `maxAvailableAssetResponse` expects the asset at `data.data`. If the Gateway
   returns it directly under `data`, the SDK decodes zeros; the test flags it.
4. **`/trade/TradeQueryHoldsList` shape.** Wrapped `{"holdsList":[...]}`, bare
   array, or single inline row (the reference documentation's form). The SDK
   tolerates all three; the test records which one is real.
5. **Push path.** That a real `/hq/Subscribe` + TCP push yields a decoded `Event`
   within 10s (mock framing is shared with the SDK, so the mock cannot prove the
   live frame).
6. **Market-pull entitlements.** Which of the nine pull endpoints the account may
   call; missing entitlements (`1006`) are reported as skips, not failures.
7. **Mutation single-attempt + entrust id.** That `TradeEntrust` returns a
   non-empty entrust id and issues exactly one outbound attempt (ADR 0003), then
   cancels cleanly.
