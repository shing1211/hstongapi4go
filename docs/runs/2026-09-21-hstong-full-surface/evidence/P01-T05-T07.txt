T05 internal/transport
- internal/transport/{doc.go,codec.go,transport.go,transport_test.go,codec_test.go}
- Envelope: {"timeout_sec":N,"params":{...}} -> {"ok":bool,"err":string,"data":{...}}
- Codec interface; JSONCodec (encoding/json); ProtoJSONCodec (protojson, rejects non-proto.Message)
- Transport.New(WithBaseURL|WithHTTPClient|WithDefaultTimeout); Concurrent-safe; immutable
- Do(ctx, op, path, params any, codec Codec, out any) error
- NO retry loop (ADR 0003); single attempt per call
- timeout_sec derives from ctx deadline when shorter than the default (min 1)
- ok=false -> *errs.Error; code recovered from the `err` string (bare code, code+text, or free text)
